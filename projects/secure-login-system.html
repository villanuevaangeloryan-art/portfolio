Sample: Secure Login System

Sample page. This is placeholder content for previewing the layout. It is not a real project.

Objective

Make a login system built with Java and Supabase safer by adding input validation and password hashing.

Overview

This project is planned and has not been started. Planned steps:

  1. Review the current login flow and note where it could be attacked.
  2. Validate and clean user input before it reaches the database.
  3. Store passwords as salted hashes instead of plain text.
  4. Test the changes with deliberately bad input.
  5. Write up what changed and why.

Technologies used

  • Java The programming language the application is written in.
  • Supabase Hosted database service that stores the application's data.
  • Secure application development Practices such as input validation and password hashing that make software harder to attack.
