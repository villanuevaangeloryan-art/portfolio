Wazuh Log Monitoring Lab

Objective

Build a small home lab where Wazuh collects and analyzes security logs from a monitored endpoint, and practice triaging the alerts it generates.

Overview

This lab is planned and has not been started. This page will be updated with the real setup, screenshots and findings as I complete each step.

Planned steps:

  1. Install a Wazuh server in a virtual machine.
  2. Connect one monitored endpoint to it with the Wazuh agent.
  3. Generate simulated failed logins on the endpoint.
  4. Review the alerts in the Wazuh dashboard and note what each one means.
  5. Write up the investigation and what I learned.

Technologies used

  • Wazuh Open-source security monitoring platform that collects and analyzes logs.
  • Wazuh agent Software on the monitored endpoint that sends its logs to the server.
  • Virtual machines An isolated lab environment, so nothing touches my main computer.
