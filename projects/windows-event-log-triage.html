Sample: Windows Event Log Triage

Sample page. This is placeholder content for previewing the layout. It is not a real project.

Objective

Practice reading Windows security logs to tell normal activity apart from events that deserve escalation.

Overview

Steps in this lab:

  1. Open Windows Event Viewer and filter the Security log.
  2. Find failed and successful sign-in events.
  3. Group the events by account and time to look for unusual patterns.
  4. Decide which events deserve escalation and note why.

Technologies used

  • Windows Event Viewer Built-in Windows tool for reading system and security logs.
  • Windows Security log The record of sign-ins and other security-related events on a computer.
  • Security log analysis Reading log entries to separate routine activity from suspicious activity.
